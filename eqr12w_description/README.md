# EQR12W 轮足机器人模型

EQR12W 描述包提供 ROS 2 URDF、MuJoCo MJCF 和去内构的中空显示外壳；Isaac Sim 可从 URDF 导入。
模型有 21 个 link、12 个腿部转动关节、4 个连续轮关节和 4 个固定轮毂座关节，
总质量 **49.71878463 kg**，已同步新腔体与自研 IP67 电机参数。

| 文件 | 用途 |
| --- | --- |
| [eqr12w.urdf](urdf/eqr12w.urdf) | ROS 2 模型、显式惯性与组合碰撞体 |
| [eqr12w.xml](urdf/eqr12w.xml) | MuJoCo 模型、地形、驱动和传感器 |
| [模型说明](urdf/eqr12w_xml说明.md) | 参数来源、惯量约定及控制接口 |
| `meshes/*_simplified.STL` | 21 个显示外壳，共 398,560 个三角面 |
| `meshes/base_link_*_support.STL` | 4 个机身底部支撑块碰撞凸包，保持原样 |

显示使用 simplified 网格；57 个碰撞体由 33 个盒体、20 个圆柱和 4 个局部凸包组成。
已删除 21 个含内部零件的原始 CAD 网格及 21 个未使用的整连杆 convex 网格。
`base_link_*_support.STL` 描述机身底部四个支撑块的斜切碰撞外形，与其余机身碰撞体同属于 `base_link`；
完整显示外壳位于 `base_link_simplified.STL`。
所有 STL 按 EQR12 的方式直接存放于 `meshes/`。地形沿用 EQR11W 的平地、坡道、平台和阶梯。

## 构建

在 ROS 2 工作区运行：

```bash
source /opt/ros/humble/setup.bash
colcon build --packages-select eqr12w_description
source install/setup.bash
```

覆盖安装会清理本包安装目录中指定的 42 个旧 CAD/整连杆凸包，避免旧版本内构网格残留；
保留其他自定义文件。已检查普通安装、`--symlink-install`、`cmake --install --prefix` 及 `DESTDIR` 暂存安装。

## MuJoCo

在安装了 MuJoCo 的 Python 环境中，从本仓库根目录运行（本次验证版本 3.8.1）：

```bash
python -m mujoco.viewer --mjcf=eqr12w_description/urdf/eqr12w.xml
```


查看器的 Geom group 1 为显示网格，group 3 为绿色半透明碰撞体；C/F 显示接触点与接触力。
home 关键帧需手动选择，模型没有站立控制器，重力下会自然落地。

## USD

当前描述包不附带 USD；从本次清理后的 `urdf/eqr12w.urdf` 重新导入 Isaac Sim。
旧的外部 USD 不会随 STL 更新，需重新导出。USD 按仓库约定仅本地保存，不加入 Git；
本地另行提供 `usd/` 时，CMake 会一同安装，移动时需保留其 `configuration/` 等相对依赖。

标准 URDF 不含关节 armature；导入后需按[模型说明](urdf/eqr12w_xml说明.md)补齐转子等效惯量、
限矩、限速及控制配置。此次测试导出的 USD 用于导入与被动仿真检查，不是训练资产或完整地形场景。

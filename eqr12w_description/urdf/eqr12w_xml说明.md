# EQR12W 模型说明

`eqr12w.urdf` 与 `eqr12w.xml` 使用相同的连杆、安装位姿、刚体惯性和碰撞体。
MJCF 网格使用相对路径 `../meshes/`，模型运行不依赖外部 `eqr32` 包。

## 参数来源与惯性约定

| 项目 | 来源与处理 |
| --- | --- |
| 几何、命名、关节位姿、转轴和角度限位 | 基于 CAD 装配模型导出，显示网格处理为去内构中空外壳 |
| 连杆质量、质心与惯量 | 轮足整机与新腔体 CAD 质量属性，保留 8 位小数 |
| 腿部电机 | HY-N8513-X32-IP67（50 Nm 级 IP67）模组参数 |
| 轮毂电机 | 转子惯量 101.72 kg·mm²、减速比 5.3、输出端扭矩限值 15 N·m |
| 摩擦与阻尼 | 保留原仿真参考值，尚未按当前电机实测标定 |
| 地形与求解器 | EQR11W 地形；PGS、50 次迭代、步长 0.0005 s |

质量单位为 kg，位置为 m，惯量为 kg·m²。TXT 的 `base_frame` 对应 `base_link`，
其余使用同名 link 的局部坐标系。惯量采用质心处、对齐输出坐标轴的 Lxx…Lzz；
SolidWorks 正惯性积取反得到 ixy、ixz、iyz，对角项保留原值，不再次做平行轴平移。

MJCF `fullinertia` 按 `Ixx Iyy Izz Ixy Ixz Iyz` 排列，直接使用 URDF 张量；
`inertiafromgeom="false"` 和几何体 `density="0"` 保证质量属性来自显式惯量。
四个 `*_leg_l4` 轮毂座保留独立惯性和固定变换，没有手工合并或重复计入质量。
当前总质量为 **49.71878463 kg**，其中机身为 20.64631829 kg。
转子折算惯量写入关节 armature，不修改 CAD 连杆质量、质心或三维惯量张量。

## 碰撞体与地形

显示网格禁用接触，57 个碰撞体在 URDF/MJCF 中保持相同形状、位置和旋转。

| 部位 | 碰撞近似 |
| --- | --- |
| 机身 | 13 个分段盒体和 4 个带斜切面的底部支撑块凸包，外尺寸 489 × 303 × 198 mm |
| 每腿髋关节 | 2 个阶梯壳体圆柱 |
| 每腿大腿 | 电机圆柱和梁盒体 |
| 每腿小腿 | 4 个分段盒体 |
| 每腿固定轮毂座 | 半径 47 mm、长度 77.6 mm 的圆柱 |
| 每个车轮 | 半径 102.5 mm、宽度 44.001 mm 的圆柱 |

四个机身底部支撑块凸包 `base_link_*_support.STL` 保留新腔体的 45° 斜切避让面，
与 13 个盒体共同构成 `base_link` 的碰撞外形，没有额外连杆、关节或质量。
完整机身显示外壳位于 `base_link_simplified.STL`；未使用的 21 个整连杆凸包已删除。
所有 STL 与 EQR12 一样直接存放在 `meshes/`，不另设碰撞网格子目录。
自碰撞开启，MuJoCo 使用默认相邻刚体接触过滤。URDF 盒体与圆柱采用完整尺寸，
MJCF 盒体采用半尺寸、圆柱采用半长度。碰撞体是工程近似，不用于重算质量或惯量。

地形包含 15 个几何体：平地、0.2 rad 双向坡道、1 m 平台及每级 0.1 m 的双向阶梯。
如另行导出完整 USD 场景，地形应保持相同尺寸与位姿；原场景约定使用 100 × 100 m 静态地面实体，顶面 Z=-0.001 m。
当前包不附带该 USD 场景，URDF 导入测试不包含这些地形。

## 电机参数与控制接口

驱动顺序为 `fl`、`fr`、`hl`、`hr`，每腿依次 `leg_1`、`leg_2`、`leg_3`、`leg_ee`。
驱动器与关节同名；MuJoCo `ctrl` 为电机侧扭矩，输出侧扭矩为 `gear × ctrl`。

| 关节组 | gear | 电机侧 ctrl / N·m | 输出限矩 / N·m | armature / kg·m² | damping | frictionloss |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A / leg_1 | 32 | ±5.625 | ±180（峰值） | 0.11173888 | 0.23 | 0.45 |
| H / leg_2 | 32 | ±5.625 | ±180（峰值） | 0.11173888 | 0.14 | 0.42 |
| K / leg_3 | 32 | ±5.625 | ±180（峰值） | 0.11173888 | 0.5 | 0.7 |
| 轮 / leg_ee | 5.3 | ±2.830188679 | ±15 | 0.0028573148 | 0.01 | 0.01 |

damping 单位为 N·m·s/rad，frictionloss 为 N·m，均为关节侧参考值，不随新减速比再次折算。
轮部采用实际关节覆盖值 0.01/0.01，而非 default class 内未生效的 0.25/0.38。

EQR12W 腿部 A/H/K 各 4 个关节均采用 HY-N8513-X32-IP67（50 Nm 级 IP67）关节模组：

| 参数 | 来源 | 数值与计算 |
| --- | --- | --- |
| 输入侧转子及直连件惯量 | 模组规格参数| 109.12 kg·mm² = 0.00010912 kg·m² |
| 总减速比 | 模组规格参数| A/H/K 均为 32 × 1 = 32，包括膝关节 |
| 输出侧等效惯量 | `J_rotor × N²` | 0.00010912 × 32² = 0.11173888 kg·m² |
| 额定/峰值输出扭矩 | 模组规格参数 | 48 / 180 N·m；除以 32 后电机侧为 1.5 / 5.625 N·m |
| 额定/峰值输出速度 | 模组规格参数 | 110 / 120 RPM；乘以 2π/60 后为 11.519173063 / 12.566370614 rad/s |
| 电压、模组质量 | 模组规格参数 | 48 V、1450 g；不替换装配后的 CAD 连杆质量 |

轮部折算：`101.72 × 10⁻⁶ × 5.3² = 0.0028573148 kg·m²`，
电机侧限矩为 `15 / 5.3 = 2.830188679 N·m`；15 N·m 未区分连续或峰值。
四个 `*_leg_ee` 关节为 continuous，未设置未经确认的轮速上限。

腿部 URDF effort 使用峰值 180 N·m，velocity 为 12.566370614 rad/s。
MJCF 的速度上限仅保存在 `custom/numeric`，需由控制器执行限速。
峰值扭矩与速度是独立上限，不表示可同时或持续达到；当前未配置扭矩–转速曲线或热模型。

## USD 接口

以下为原本地 IsaacLab 0.54.2 / Isaac Sim 5.1.0.0 资产的控制配置约定；当前包不附带 USD，
显示外壳更新后须重新导出并显式配置，不能视为普通 URDF 导入后自动具备。
训练资产应按需要保留浮动基座、固定关节及自碰撞；本次被动导入测试合并固定关节并关闭自碰撞。
腿部应设置 `physxJoint:armature=0.11173888`、angular drive `maxForce=180`，
`physxJoint:maxJointVelocity=720` deg/s；运行时速度接口使用 rad/s。
轮部 armature=0.0028573148、maxForce=15；所有 drive stiffness/damping 均为 0。

减速比作为元数据保存，PhysX 不会自动根据它换算扭矩。直接力矩接口采用关节输出侧 N·m，
电机侧输入由控制器乘腿部的 32 或轮部的 5.3，并自行限幅到 ±180 / ±15 N·m。
已经折算的 armature 不要再乘减速比平方。标准 URDF 没有 armature 字段，重新转换 USD 时需补写上述参数。
MJCF 被动损耗不等同于 PhysX drive damping，损耗模型和传感器需在控制环境中配置。
原导出资产的 PhysX 关节排列为四腿 leg_1、四腿 leg_2、四腿 leg_3、四个 leg_ee；
重新导入后应按名称映射控制量，不依赖固定索引。

## 初始姿态与传感器

浮动基座为三个平移关节加一个球关节，`nq=23`、`nv=22`、`nu=16`。
基座参考位置为 `(8, 0, 0.465)` m，前三个 qpos 是相对此位置的平移。
默认重置使用 CAD 零位；home 每腿为 `(0, -1.3, 1.6, 0)` rad，基座高度约 0.6291076366 m。
home 只设置姿态，保持站立或行走需接入控制器。

传感器包括 16 个 jointpos、16 个 jointvel、16 个 actuatorfrc 和 6 个基座/IMU 传感器，
共 54 个传感器、67 个标量输出。`*_f` 为电机侧输出，折算关节扭矩需乘以 gear。
IMU site 位于 base_link 原点；另提供 `track` 观察相机。

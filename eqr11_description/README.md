# EQR11 模型说明

## 外观：EQR11W 风格（2026-11-24）

机身原始 CAD 与 EQR11W 相同。本版复用同源机身、护板、传感器外表面与外部标识。显示网格按材质拆成二进制 STL，URDF 和 MJCF 分别指定浅灰外壳、深色机腹、深色金属电机及灰绿色传感器盖板等材质。所有运行时资产均在本包内。

显示资源为 **23 个视觉连杆、34 个分色 STL、85,106 个三角面、4.06 MiB**；连同 4 个机身碰撞 STL，当前 `meshes/` 共 38 个二进制 STL、4.07 MiB。显示网格保留逐面顶点顺序、米制坐标和分色。STL 存储单精度顶点和面法线，原 OBJ 的逐角法线无法写入，曲面高光可能随渲染器的平滑方式略有变化。

## 急停、电机与空腔

急停位于机身后侧，局部坐标 `x=-0.231 m, y=0`。帽盖为直径 **30 mm** 的红色圆形，局部高度 `z=0.043–0.047 m`；前侧 `x=+0.231 m` 没有对应的凸起帽盖或底座，保留平整顶面。

四腿髋部与大腿电机保留外表面轮廓，在 `x=-0.08 m` 和外侧 `|y|=0.12 m` 处与当前连接外罩裁接。大腿浅灰护板沿用 EQR11W 的外形。此前的 OBJ 版本已逐连杆检查闭合性，逐闭合分量的自交面检查为 0。

机身核心空腔不保留电池架、隔板、PCB、传动或电机内部网格。外部文字、按钮、盖板和四处偏黑肩部封盖按参考风格保留，不能将这些外部附件的独立分量理解为内部零件。核心区域 `|x|<0.14 m, |y|<0.115 m, -0.12<z<0.025 m` 无视觉顶点；12 条贯穿射线在此空腔内无命中。外侧盖板、窗口或标识可能带来额外表面命中。36 条肩部封口射线均命中外罩。

## URDF、MJCF 与物理约定

标准 URDF 使用 `package://eqr11_description/meshes/`。URDF 和 11 份机器人 MJCF 已同步使用同一套 34 个视觉文件、材质和局部坐标；视觉几何为无碰撞、零密度。原有物理地形网格及其引用保留。

质量、惯量、质心、关节、驱动、足端检测和传感器坐标沿用原值。完整版约 49.714688 kg，sensor 及派生场景约 48.198027 kg，保留原有传感器质量约定。四路相机的位姿、分辨率和内参不变。

此前外观版本验证包括：34 个文件的哈希及引用、23 个连杆合并分色后的闭合性与绕序、逐分量自交、后侧圆形急停与前侧无凸起检查、核心空腔及肩部封口射线；URDF 直接加载、11 份 MJCF 非视觉声明和物理数组比对、各 1000 步同输入状态逐位一致。

## 碰撞体（2026-11-25）

恢复短机身版本的 37 个原有碰撞体，在机身前后各增加 2 个斜面凸块，共 **41 个碰撞体**。腿部、足端及机身原有 5 个基本体的形状、尺寸和位置与原版一致；新增补块侧边内收，为髋关节活动留出空间。标准 URDF 与 11 套 MJCF 同步，显示外观、质量惯量、关节及接触过滤不变。

MuJoCo `Geom group 3` 显示碰撞体，`group 1` 显示外壳。原有碰撞配置逐项核对通过；13,170 个姿态中未发现新增补块的误碰撞，检查时关闭相邻连杆过滤。ROS、MuJoCo 加载、被动仿真及覆盖安装通过。结果限于已测姿态，未验证完整训练或实机运动；使用外部 USD 时需重新生成资产。

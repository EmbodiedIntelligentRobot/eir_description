# EQR11 点足 URDF 与 MJCF 惯量来源

2026-11-04 根据点足 CAD 质量属性更新
[eqr11.urdf](urdf/eqr11.urdf) 的 23 个有效 `<inertia>`，共 138 个数值。
质量、质心位置、惯性坐标系姿态、关节、网格和碰撞定义保留原值。
原质量和质心与来源文本相近，但精度不同；本次没有用文本的舍入值覆盖原值。

## 单位、参考点与符号

采用每段的 `Lxx/Lxy/Lxz/Lyy/Lyz/Lzz`，即“由重心决定，并且对齐输出的坐标系”一组。
不采用第二组相对于输出坐标系原点的 `Ixx/...`，避免重复计入质心平移。

原单位为 g·mm²，URDF 单位为 kg·m²，换算系数为 `1e-9`。
该报告采用 SolidWorks 正张量记数法，交叉项是正号定义的惯性积；
URDF 存储惯性张量的实际非对角元素，因此转换为：

```text
ixx =  Lxx × 1e-9     iyy =  Lyy × 1e-9     izz =  Lzz × 1e-9
ixy = -Lxy × 1e-9     ixz = -Lxz × 1e-9     iyz = -Lyz × 1e-9
```

符号由来源中的 `Px/Py/Pz` 交叉核对：转换后 23 组张量的特征值与所列主惯量
最大差异约 `8.69e-13 kg·m²`。直接照抄交叉项的符号不能通过该核对。
所有惯性坐标系均保留 `rpy="0 0 0"`；非对角元素决定主轴方向，无需再填入一次主轴旋转。

## MJCF 同步

同日将新张量同步到 11 份机器人 XML，共更新 153 个有效 `<inertial>`。
MJCF 采用 `fullinertia="ixx iyy izz ixy ixz iyz"`，单位为 kg·m²，
数值直接来自已转换的 URDF，不再对交叉项取反。
原 `diaginertia` 和对应的惯性主轴 `quat` 被完整张量替代，主轴由 MuJoCo 求解；
body 的安装姿态不变，避免把旧主轴旋转重复应用到新张量上。

| XML | 惯量处理 |
| --- | --- |
| `urdf/eqr11.xml` | 23 组，逐 link 同步；`fl/fr/hl/hr_foot` 对应 URDF 的 `fl/fr/hl/hr_leg_lee` |
| `urdf/eqr11_sensor.xml` | 13 组，机身及 leg1/leg2 直接同步，leg3 保留原小腿与足端合并方式 |
| `urdf/eqr11_ground.xml`、`eqr11_suspended.xml` | 与 sensor 同步 |
| `urdf/eqr11_slope_20deg.xml`、`eqr11_slope_30deg.xml`、`eqr11_slope_40deg.xml` | 与 sensor 同步 |
| `urdf/eqr11_stairs_10cm.xml`、`eqr11_stairs_30cm.xml`、`eqr11_stairs_40cm.xml`、`eqr11_stairs_50cm.xml` | 与 sensor 同步 |

合并小腿的质量保持 `0.50651 + 0.081871 = 0.588381 kg`。
足端先按 URDF 固定关节平移 `0.24424 0 -0.11649 m` 到小腿坐标系，
再相对 XML 已保存的合并质心，用平行轴定理合成两者的完整惯量：

```text
I = Σ [I_i + m_i (||d_i||² E - d_i d_iᵀ)]
```

本模型的足端固定关节及 URDF 惯性坐标系旋转均为零，故无需额外旋转；
`d_i` 是部件质心相对合并质心的偏移。前后足端的质心 y 值不同，分别计算。
保留 XML 原有合并质心精度，其与精确加权质心的最大坐标差为 `2.79e-7 m`；
使用该保存位置计算引入的张量差不超过 `4.71e-14 kg·m²`。
不在无惯量的 foot body 上重复添加质量。

本次保留各 XML 既有质量、质心、运动学、碰撞、执行器、相机与地形。
基础 `eqr11.xml` 含六个传感器的质量，总质量约 `49.714688 kg`；
sensor 及其派生场景原本未计入这些传感器质量，总质量约 `48.198027 kg`。
这项既有差异没有在此次惯量同步中更改，不能据此宣称两类模型整机动力学完全相同。
相机 include `eqr11_policy_cameras.xml` 没有惯量，不需要修改。

## 验证与生效范围

URDF 解析、23 组张量正定性、主惯量三角不等式及来源主惯量核对通过。
MuJoCo 3.4.0 可加载原 URDF；额外关闭惯量自动平衡及固定连杆合并检查时，
编译后主惯量与 URDF 特征值最大差异约 `1.78e-15 kg·m²`。
由 MuJoCo 的主轴四元数重建张量存在数值近似，最大相对 Frobenius 误差约 `5.19e-7`。
首次逐元素 `atol=1e-10, rtol=1e-8` 检查未通过，不能声称重建张量逐元素精确一致；
没有因此改动源惯量或开启自动平衡。

上述 11 份 XML 均通过 MuJoCo 3.4.0 加载和一次 `mj_forward`，结果为有限值且无运行警告。
153 组张量正定且满足主惯量三角不等式；编译后主惯量最大误差约 `1.78e-15 kg·m²`，
主轴重建张量的最大相对 Frobenius 误差约 `5.19e-7`。
逐文本排除惯量表示属性后与修改前一致，sensor 与九个派生场景的惯量定义完全相同。

直接加载这些副本的仿真仍使用其原惯量。
